🔑 Tutorial: Obtener tu API Key gratis

Paso 1: Ingresar a Google AI Studio

Haz clic en el enlace de abajo para abrir la consola de desarrolladores de Google de forma gratuita:

👉 Abrir Google AI Studio
Paso 2: Iniciar Sesión

Inicia sesión utilizando cualquier cuenta normal de Google o correo institucional de Gmail.

Paso 3: Crear la API Key

En el menú lateral izquierdo o superior, haz clic en el botón azul destacado que dice "Get API Key" (Obtener clave de API) y luego presiona "Create API Key".

Paso 4: Copiar y Pegar en el Visor

Copia la cadena de texto generada (esta comenzará siempre con los caracteres AIzaSy...) y pégala en el campo de texto ubicado en el lateral de este visor.

🔒 Privacidad del Visor: Tu API Key se almacena únicamente de forma local en tu navegador (Local Storage). Ningún servidor de terceros ni personal externo tiene acceso a ella.
